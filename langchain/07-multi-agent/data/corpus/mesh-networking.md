# Mesh networking

A mesh network connects many nodes so that data hops from node to node toward
its destination, instead of routing everything through a single access point.

- Each node relays traffic for its neighbours, so coverage grows as nodes are
  added.
- If one node fails, traffic reroutes around it, so the network self-heals.
- There is no single point of failure, unlike a hub-and-spoke layout.
- Throughput can drop as a packet takes more hops to reach the gateway.
- Mesh networks are common in smart-home sensors and community wireless projects.
- Adding a node extends range without running new cable to a central router.
